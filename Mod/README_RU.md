# Crysis Coop

Одиночная кампания Crysis (2007) на 2–4 игроков. Хост проходит кампанию как
обычно: враги, сюжет, ролики. Друзья подключаются к нему через интернет по
короткому коду, ничего не настраивая на роутере.

*English: [README.md](README.md)*

## Что нужно

* Crysis (2007) версии 1.2.1: подходят GOG, Steam и EA. Для DVD-версии нужны официальные патчи 1.2 и 1.2.1.
* Своя копия игры и мода у каждого игрока.
* Windows 8 или новее.

## Установка

Запустите `install.bat` из архива выпуска. Установщик:

* найдёт игру;
* при необходимости поставит [C1-Launcher](https://github.com/ccomrade/c1-launcher) (оригинальный `Bin32\Crysis.exe` сохранится как `Crysis.exe.original`);
* скопирует мод в `Mods\Coop`;
* соберёт кооп-версии уровней кампании из файлов вашей игры (почти без места на диске, оригинальные файлы не меняются);
* создаст ярлык **Crysis Coop** на рабочем столе.

Без скачивания архива (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/SeniorStackOverflow/crysis-coop/releases/latest/download/install.ps1 | iex"
```

## Как играть

**Хост:** запустите **Crysis Coop**, откройте консоль (`~`) и введите

```
coop_host
```

Кампания начнётся с первого уровня. Сохранений в коопе нет, поэтому начать с другого уровня можно, указав его имя:
`coop_host village`. Уровни: island, village, rescue, harbor, tank, mine, core, ice, sphere, ascension, fleet (или номер `1`–`11`).

Когда уровень загрузится, на экране появится код, например `Co-op code: 64117`.

**Друг:** запустите **Crysis Coop**, откройте консоль и введите код хоста:

```
coop_join 64117
```

Друг появится рядом с хостом, когда тот приземлится или закончится вступление уровня. В конце уровня все вместе переходят на следующий, код не меняется.

## Консольные команды

| Команда | |
|---|---|
| `coop_host [уровень]` | создать кооп-игру |
| `coop_join <код>` | подключиться к игре друга |
| `coop_relay_status` | код, кто подключён, задержка |
| `coop_tp` | телепорт к лидеру (если застряли) |
| `coop_status` | игроки и их состояние |
| `coop_direct 0` | не соединяться напрямую, всегда через сервер мода |
| `coop_english_keyboard 0` | оставить в окне игры системную раскладку |

## Соединение

Сервер мода связывает хоста с друзьями. Сразу после подключения компьютеры
ещё и пытаются соединиться напрямую (UDP hole punching). Обычно это удаётся
за секунду, и тогда задержка такая же, как между вашими компьютерами
напрямую. Где напрямую нельзя (строгий NAT, закрытый UDP), игра продолжает
идти через сервер мода.

## Полезно знать

* Погибший игрок через 8 секунд появляется рядом с напарником.
* Враги, задания, ролики и сюжет — хоста. Друзья видят их и проходят вместе с ним.
* Если хост выходит, игра заканчивается для всех.

## Удаление

Запустите `Mods\Coop\uninstall.ps1` (с `-RestoreLauncher` вернётся и оригинальный `Crysis.exe`).
