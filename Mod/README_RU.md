# Crysis Coop

Одиночная кампания Crysis (2007) на 2–4 игроков. Хост проходит кампанию как
обычно: враги, сюжет, ролики. Друзья подключаются к нему через интернет по
короткому коду, ничего не настраивая на роутере.

*English: [README.md](README.md)*

## Что нужно

* Crysis (2007) версии 1.2.1: подходят GOG, Steam и EA. Для DVD-версии нужны официальные патчи 1.2 и 1.2.1.
* Своя копия игры и мода у каждого игрока.
* Windows 8 или новее.

## Установка

Запустите `install.bat` из архива выпуска. Установщик:

* найдёт игру;
* при необходимости поставит [C1-Launcher](https://github.com/ccomrade/c1-launcher) (оригинальный `Bin32\Crysis.exe` сохранится как `Crysis.exe.original`);
* скопирует мод в `Mods\Coop`;
* соберёт кооп-версии уровней кампании из файлов вашей игры (почти без места на диске, оригинальные файлы не меняются);
* создаст ярлык **Crysis Coop** на рабочем столе.

Без скачивания архива (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/SeniorStackOverflow/crysis-coop/releases/latest/download/install.ps1 | iex"
```

## Как играть

**Хост:** запустите **Crysis Coop**, откройте консоль (`~`) и введите

```
coop_host
```

Начнётся новая кампания с первого уровня. Начать с другого уровня можно, указав его имя:
`coop_host village`. Уровни: island, village, rescue, harbor, tank, mine, core, ice, sphere, ascension, fleet (или номер `1`–`11`).
Следом можно дать кампании имя: `coop_host island С Сашей`.

Чтобы продолжить с того места, где остановились в прошлый раз, хост вводит вместо этого

```
coop_continue
```

Когда уровень загрузится, на экране появится код, например `Co-op code: 382615`. У одного и того же хоста код всегда один и тот же.

**Друг:** запустите **Crysis Coop**, откройте консоль и введите код хоста:

```
coop_join 382615
```

В следующий раз хватит просто `coop_join`: друг подключится к тому же хосту. Друг появится рядом с хостом, когда тот приземлится или закончится вступление уровня. В конце уровня все вместе переходят на следующий.

## Сохранения

Игра хоста сама сохраняет прогресс, как одиночная кампания: в начале
каждого уровня и на контрольных точках кампании (у всех на экране «Игра
сохранена»). Хост может сохраниться и в любой момент командой `coop_save`.

* `coop_continue` запускает самую свежую кампанию с её последней контрольной
  точки: уровень со всем, что на нём уже сделано, хост там, где был. Друзья
  получают обратно оружие, которое было у них на этой точке.
* `coop_load` возвращает на последнюю контрольную точку прямо посреди игры.
* Когда игра хоста перезапускается (`coop_load`, `coop_continue`, новая игра)
  или у него пропадает связь, игры друзей ждут его и подключаются снова сами:
  «The host is loading the game».

**Кампании.** Каждый `coop_host` начинает отдельную кампанию, новая игра
старую не затирает.

* `coop_campaigns` показывает список (с номерами, свежие сверху).
* `coop_continue 2` или `coop_continue С Сашей` выбирает кампанию.
* `prev` — на одну точку раньше: `coop_continue prev`, `coop_load prev`.
* `coop_campaign_delete 3` удаляет кампанию.

**Облако.** Каждая контрольная точка хранится ещё и на сервере мода, для всех,
кто играл в этой кампании.

* Кампания не привязана к одному компьютеру: любой друг, который в ней играл,
  может сделать `coop_continue` и стать хостом (игра скачает свежую точку).
  Остальные подключаются к нему как обычно.
* `coop_cloud 0` оставляет ваши контрольные точки только на вашем компьютере.

Прогресс хранится в `Документы\My Games\Crysis\SaveGames`: папка `coop` и
сохранения `coop_checkpoint_*`.

## Консольные команды

| Команда | |
|---|---|
| `coop_host [уровень] [имя]` | начать новую кооп-кампанию |
| `coop_continue [номер или имя] [prev]` | продолжить кампанию с последней точки |
| `coop_load [prev]` | вернуться на последнюю точку (хост, во время игры) |
| `coop_save` | сохраниться сейчас (хост) |
| `coop_campaigns` | кампании на этом компьютере и в облаке |
| `coop_campaign_delete <номер или имя>` | удалить кампанию |
| `coop_join [код]` | подключиться к игре друга (без кода — к последнему) |
| `coop_leave` | выйти из игры друга |
| `coop_relay_status` | код, кто подключён, задержка |
| `coop_tp` | телепорт к лидеру (если застряли) |
| `coop_status` | игроки и их состояние |
| `coop_cloud 0` | не хранить контрольные точки на сервере |
| `coop_direct 0` | не соединяться напрямую, всегда через сервер мода |
| `coop_english_keyboard 0` | оставить в окне игры системную раскладку |

## Соединение

Сервер мода связывает хоста с друзьями. Сразу после подключения компьютеры
ещё и пытаются соединиться напрямую (UDP hole punching). Обычно это удаётся
за секунду, и тогда задержка такая же, как между вашими компьютерами
напрямую. Где напрямую нельзя (строгий NAT, закрытый UDP), игра продолжает
идти через сервер мода.

## Полезно знать

* Погибший игрок через 8 секунд появляется рядом с напарником.
* Враги, задания, ролики и сюжет — хоста. Друзья видят их и проходят вместе с ним.
* Если хост выходит, игра заканчивается для всех.

## Удаление

Запустите `Mods\Coop\uninstall.ps1` (с `-RestoreLauncher` вернётся и оригинальный `Crysis.exe`).
